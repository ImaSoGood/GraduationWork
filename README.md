Здравствуйте! Представляю вам часть моей дипломной работы, по теме: автоматизированный сбор и анализ данных с удаленных информационных ресурсов.
Эта часть посвящена Серверу: Python и клиент-серверным скриптам. Клиент-сервер написан на PHP, работает с базой MySQL. Python-скрипты выполняют роль парсеров, тянут данные с сайта по ссылке, формируют ответ, и далее отправляют его в PHP функции, которые далее распределяют это дело.
В функции скриптов входит: 
  - Авторизация/регистрация пользователя
  - Парсинг и формирование ответа для моб. приложения
  - Постановка запроса к сбору данных на мониторинг (мониторинг должен был производиться каждый час, по факту все для этого было готово, кроме запуска интервала времени. ID постов, которые парсер ранее не находил, помечал как новые, обновлял запрос и ставил на него красный флажок (уже в моб. приложении)). Для диплома прокатило). Я буквально запустил скрипт обновления содержимого запросов будучи уже на трибуне).
  - Отслеживание на наличие новых постов с запчастями по запросам, поставленным на обновления. (Например ищу я шаровую опору на "Toyota ... модель". Не нашел в выданных мне постах ни одной подходящей, поставил запрос на мониторинг. Через пару дней флажок загорается красным, значит появился новый идентификатор в постах, соответственно новый пост. И о чудо, вот она, нужная шаровая...осталось списаться с продавцом.)
  - Отправка уведомления пользователям, при обнаружении новых постов. (По крайней мере на момент 2023-2024, уведомления хорошо функционировали используя только токен Android-устройства, и запрос в Google.api с содержанием токена авторизации на Google-сервисы).
